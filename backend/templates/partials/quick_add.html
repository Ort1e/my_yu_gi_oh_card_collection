Quick add from a set

Type the set code as printed on the cards, with the language (e.g. RA05-FR), then each card's number. A full code (MAMO-EN012) is used as typed, whatever the set above. A number printed in several rarities gets one row per copy: choose each one's rarity in its row.

Or paste a list of numbers or codes
